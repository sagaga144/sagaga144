### 🧠 What I'm building

- **[Gymion](https://gymion.fit)** — AI fitness platform (PWA + native Android/iOS via Capacitor). Gemini-powered workout generation with a WebLLM offline fallback and a deterministic algorithmic fallback under that, video form analysis, real-time social features, full Hebrew/English RTL support, 676 automated tests.
- **[claude-harness-bootstrap](https://github.com/sagaga144/claude-harness-bootstrap)** — a Claude Code plugin that builds a complete, project-specific harness (agents, guard hooks, commands, a learning-memory loop) from a one-paragraph project description. No Claude Code experience required to use it.
- **Verdoc** — a documentation business run entirely by an autonomous AI agent, governed by a constitution the agent can't edit itself. Four independent guardrail layers, red-teamed on purpose. Live agent-to-agent payment infrastructure, still proving out demand.
- **[Top Burger](https://top-burger-20976.web.app)** — a social food-rating app (React Native + Expo), global restaurant search with no API key required, a live leaderboard, Hebrew/English i18n. Deployed to iOS, Android, and web.
- **Fake Review Checker** — a privacy-first browser extension that grades Amazon review authenticity. Zero network calls, everything scored on-device. Pre-launch.
